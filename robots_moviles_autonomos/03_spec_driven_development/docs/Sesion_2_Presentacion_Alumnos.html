2 · Convertir a SPEC

A partir de la transcripción anterior, prepara una especificación breve en Markdown llamada SPEC.md. Incluye: objetivo, usuario, interfaz, requisitos R1...Rn, criterios de aceptación A1...An, fuera de alcance y dudas. No añadas funciones. Distingue lo dicho por el usuario de tus propuestas. Antes de dar la versión final, pregunta solo las decisiones que bloquean la implementación. No escribas código todavía.

Lee SPEC.md. Primero resume el programa y propón un plan de cuatro pasos. Si hay requisitos contradictorios o pendientes importantes, pregunta antes de programar. Funciones sencillas; sin servidores, base de datos ni funciones extra. Instala dependencias solo con mi autorización. Ejecuta las pruebas, corrige fallos y explica cómo abrir la ventana. SESIÓN 2 · PYTHON + IA

Descripción del issue

@IA

## Mejora
Añadir un botón Intercambiar unidades al conversor.

## Comportamiento
Al pulsarlo, intercambia Origen y Destino. Conserva el texto escrito en Valor y borra el resultado anterior; no convierte automáticamente. El botón Convertir sigue funcionando igual.

## Aceptación
- mm → m pasa a m → mm.
- Valor conserva exactamente el texto que tenía.
- El resultado vuelve a —.
- Pulsarlo dos veces restaura las unidades.
- Las pruebas anteriores siguen pasando.

## Alcance
Actualizar SPEC.md con la mejora y añadir tests/test_mejora.py si hay nueva lógica. No instalar dependencias ni cambiar el sistema de automatización.
