# Robots Móviles Autónomos

Material y prácticas de la asignatura **Robots Móviles Autónomos**.

## Prácticas y programas

| # | Carpeta | Descripción |
|---|---|---|
| 01 | [01_calculadora_interfaz](./01_calculadora_interfaz/) | Calculadora de escritorio en Python (Tkinter), estilo Windows 11: operaciones aritméticas, funciones extendidas, teclado y gestión de errores |
| 03 | [03_spec_driven_development](./03_spec_driven_development/) | Conversor de longitudes (mm/cm/m) desarrollado a partir de especificación (SDD/TDD): CLI, GUI Tkinter y pruebas unitarias |

### Ejecución rápida (práctica 01)

```powershell
cd 01_calculadora_interfaz
python calculadora_windows.py
```

Ver informe de entrega y tabla de pruebas en el [README del módulo](./01_calculadora_interfaz/README.md).

### Ejecución rápida (práctica 03)

```powershell
cd 03_spec_driven_development
.\run.bat
```

Ver [README del módulo](./03_spec_driven_development/README.md) y la spec [gemini-code-specs-drive.md](./03_spec_driven_development/gemini-code-specs-drive.md).
